## Objective

Deliver a production-capable Kundu Electronics electronics-components store in Khulna, Bangladesh. Prices are BDT (৳). SparkFun informs information architecture and shopping patterns; use Kundu's own branding and verified business data.

## Architecture

- Next.js 16.4.6 App Router, React 19.3.0, strict TypeScript and Tailwind CSS 4.3.3.
- Modular monolith with Supabase PostgreSQL/Auth/Storage integration.
- Separate browser, public-server and privileged server Supabase clients; privileged client is server-only.
- Next.js 16 `src/proxy.ts` handles auth cookie refresh.
- Public business settings are centralized in `src/config/business.ts`.
- Public products contain selling prices only; no purchase-cost property is in the public Product type.
- Catalogue data is fetched via Supabase views/RPC; catalogue remains unpublished/empty until owner approval.
- Money is represented as integer BDT (`BIGINT` in SQL), never floating point for authoritative totals.
